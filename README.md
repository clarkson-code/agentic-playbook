# agentic-playbook

Reusable patterns and playbooks for agentic development workflows.

Each pattern is proven in practice and comes with a ready-to-use prompt or 
config you can drop into your own projects.

## Contents

| Playbook | Description |
|---|---|
| [speckit-playbook](./speckit-playbook/) | Patterns for teams using SpecKit with Claude as the agent |

## Contributing

Found a pattern that works? Open a PR. The bar is simple — it must be proven 
(not theoretical) and include something others can use immediately.
